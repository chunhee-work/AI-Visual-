**Rule (locked 2026-06-10):** When designing 6-panel storyboard sheets where hero is fighting Whisper+Village adversaries, three constraints apply ACROSS all panels for cinematic continuity:

1. **Multiple adversaries required** — show 4-5 wrinkled elder peasant adversaries (per Image B/C reference) as a cluster, NOT just one or two. Single-adversary background reads as sparse and tense for combat scenes.

2. **Consistent adversary cluster position across panels** — the adversaries should appear in EXACT SAME physical X-Y location across all panels where they're visible, NOT just "approximately the same area". Example: 4-5 adversaries clustered at frame-LEFT MID-GROUND advancing toward the hero — that same cluster position carries through Panel 2 (background while hero enters), Panel 3 (background while hero winds up), Panel 5 (origin position before radial knockback). After knockback panels (e.g., bird's-eye P5 after impact) may show them in radial pattern but originating from the SAME EXACT starting cluster position. **REINFORCED 2026-06-10**: user feedback on GST V1 P3 vs P5 — adversary positions in P3 (pre-attack advance) and P5 (knocked back by lightning) must be in the IDENTICAL XY position. P3 = adversaries advancing TOWARD final position. P5 = adversaries getting knocked back FROM that same final position. Same exact spot, just different motion vectors.

3. **Foreground hero element panels don't redundantly show full hero in background** — if Panel 2 shows the hero's BOOT landing (extreme detail entrance), the BACKGROUND should show ADVERSARIES (the threat motivating the entrance), NOT another full hero figure. The slot is reserved for narrative context (threat / environment / fellow hero), not hero duplication.

**Why:** 2026-06-10 — user feedback on CCATS storyboard V1 rendered with:
- Panel 2 showed CCATS's boot in foreground + ANOTHER full CCATS in background (redundant)
- Panel 3 showed 4 adversaries clustered frame-LEFT
- Panel 5 showed adversaries scattered radially (different positions)
- User feedback: "why is the 2 panel showing CCATS the leg correct but CCATS with the whole one should not be there right, it should be the Village + Whisper... i want multiple Village + Whisper inside not just one same. and make sure every panel of the Village + Whisper position same. as u see panel 3 & panel 5 their position different."

**How to apply (per panel):**

1. **Identify the "adversary cluster" position** at start of storyboard design — pick a specific location like "frame-LEFT MID-GROUND advancing toward hero" or "frame-DEEP background pushing forward". Lock this position.
2. **In every panel where adversaries appear**, place them in approximately that same position with consistent count (4-5 figures).
3. **Foreground-hero-detail panels** (boot landing / hand gripping weapon / fist macro): show ADVERSARIES in background at the locked cluster position, NOT the full hero — the foreground detail IS the hero, the background completes the visual narrative.
4. **After-impact panels** (bird's-eye knockback / radial scatter) — adversaries arc outward from the locked starting cluster position. The radial pattern is the AFTERMATH of the same cluster's positions, not new figures.
