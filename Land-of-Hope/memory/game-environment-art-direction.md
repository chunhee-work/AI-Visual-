The "AI Visual" work includes a casual idle / management tycoon game (My Mini Mart-style: mini-supermarket + farm, 3D low-poly cartoon, ¾ isometric, stickman characters) that must visually match the user's website **"The Chill Gallery"** — a dark premium TCG / gacha collector site: near-black + deep teal-green radial glow, neon-teal primary accent, gold/amber secondary, glassy cards with thin glowing borders, fine starfield particles.

**Locked environment "balance" (2026-05-22):** keep the bright, readable daytime My Mini Mart playable layer, but grade/light it to belong to the Chill Gallery brand — teal-mint ground, glowing cyan-teal rim accents + emissive on interactables (upgrade tiles, registers, fences), gold/amber currency highlights, gentle bloom, fine floating light-dust particles, subtle deep-teal edge vignette. The user picked "bright + brand glow" over a dusk/dark version. Tagline: "premium hyper-casual." Environment plates are built character-free / clean (no HUD baked in) for reuse; faceless stickman NPCs optional for life.

**Why:** User said "find the balance" between the game style refs and the website UI on 2026-05-22, and chose the bright-with-brand-glow direction + a master establishing plate first.

**How to apply:** Use [[active-creative-skill-stack]] → banana-pro-director Mode 3 (scene/environment plates) with an EXPLICIT stylization override. The 10 mascots, however, are detailed **hand-painted 2D illustrations** (painterly shading, soft line work, storybook / premium mobile-RPG / chibi look), so they clashed with the low-poly world.

Tried two fixes in order: (1) place the mascots on the map re-rendered as low-poly — gap still read "too far"; (2) re-paint the ENVIRONMENT into the mascots' 2D illustrated style — **that didn't work** either. 

**FINAL DECISION:** keep the **3D low-poly environment** (it was working) and **convert the 10 mascots into 3D low-poly to match it**. Delivered 10 per-character conversion prompts (identity-locked, ¾ front, smooth matte low-poly, attach character sheet as image 1 + low-poly map as image 2). So the locked game art style is **3D low-poly cartoon for BOTH world and characters**, with the teal-mint + cyan-glow + gold brand palette. The detailed 2D illustrated mascot sheets remain the identity/source reference only. Next likely steps: low-poly 6-panel turnarounds / 8-dir walk sets per character, then redo the map-placement prompt once all are low-poly.
