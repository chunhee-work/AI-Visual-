**Rule (locked 2026-06-09):** When writing prompts that feature OG10 characters WITHOUT their turnaround attached as a ref (e.g. group shots where only OG10 lineup is referenced), describe each character per the canonical design below. **Why:** 2026-06-09 — Sheet 2 (SKET + FROAK) rendered both heroes as HUMAN figures because my prompt said "samurai-warrior hero" + "kung-fu master hero" without specifying anthropomorphic animal.
