For the AI Visual game's 10 mascots ([[game-environment-art-direction]]), the user makes a **6-panel character turnaround sheet** per character on Banana Pro. Locked layout (this exact wording works): clean white seamless studio backdrop, six panels — top-left full-body front, top-center full-body rear, top-right full-body left profile, far-right three-quarter standing pose, bottom-center tight face close-up straight-on, bottom-right tight three-quarter face close-up; character identical in every panel, only the angle changes.

**Locked render style = "3D form + painterly 2D texture" (final, 2026-05-22):** a stylized 3D character (real three-dimensional form, volume, depth, soft dimensional studio lighting + soft shadows) whose every surface carries **hand-painted painterly 2D texture / visible brushwork baked into the materials** — painterly shading and color, NOT slick photoreal materials. This is the "hand-painted 3D stylized game art" look (Overwatch / WoW cinematic register) and it is what finally nailed the user's 2D↔realistic balance: 3D gives depth/realism, painterly texture keeps the 2D illustrated soul. Guards stay: keep stylized chibi/cat proportions + charm; NEVER a real human/animal; NOT flat 2D cel-shaded line art; NOT a slick photoreal render; NOT a photograph.

**Why:** User iterated through several style attempts on the ECOX robot before landing here: (1) first prompt too photoreal → turned the robot into a generic real-human woman; (2) "flat 2D cartoon"; (3) "find the balance — realistic skin/detail but not too real like a human" → semi-realistic; (4) finally specified "**3d rendered with painterly 2d texture**" — the locked answer. The frog plumber turnaround is the closest existing reference for the detail level.

**The two load-bearing prompt tricks (this is the hard-won fix):**
1. **Anchor + forbid:** "Use the attached reference as the exact source… do NOT convert it into a real human or a photograph, NEVER a real-world person." The old prompt's "photorealistic / Shot on Arri Alexa 85mm / her appearance" was secretly a real-human-photo instruction — fine on an already-detailed creature (frog), but it discarded the simple chibi robot and defaulted to a stock photoreal woman.
2. **Collectible-figure framing for material realism without the human collapse:** "render as if it were a real physical premium collectible figure photographed in a studio." Grounds photoreal materials/lighting in a stylized object, so the subject can't slide into a real person. Used at full strength for the ECOX robot; for human characters dial to the "2D↔realistic balance, realistic skin but never a real human"; the two cats (esp. SKET) can lean fully realistic like the frog.

**How to apply:** One prompt per character. Build the six-panel turnaround **from the single hero ref** AND apply the finish in one pass (the user supplies single hero refs, not pre-made sheets). If a one-pass sheet comes out flat, run a plain turnaround first, then re-grade with the finish as a second pass. Keep the user's own brand text on costumes (GST ELECTRICAL, SKET, KETDONUT, 自由, ラーメン/麺) — it's their IP, present in the refs. Deliver every prompt bilingually EN + 中文 per [[bilingual-mandarin-responses]]. "3D + painterly 2D texture" prompts delivered for the 7 (GST, nurse, KETDONUT, lychee, SKET, scholar, ramen). ECOX still on the older glossy collectible-figure look — re-render it in the painterly style for full consistency. Frog turnaround predates the lock.

**ANIMAL/CREATURE GUARD (2026-05-26):** The cat/frog turnarounds keep drifting into a *photoreal real animal* (documentary fluffy-cat fur + literal cat face) — the user rejects this. Animal/creature sheets MUST read as a **stylized-but-realistic Pixar/Disney/DreamWorks animated CHARACTER**: appealing gently-exaggerated cartoon proportions, larger expressive eyes with bright catchlights, rounder charming stylized head/muzzle — while still carrying realistic painterly fur + material detail. The user's **KETDONUT turnaround is the named gold-standard reference** for this look (point other sheets at it as a style ref via the two-image method). CCATS + SKET battle turnarounds came out too photoreal and were re-styled to match KETDONUT. Human faces still get the "real skin with flaws, not plastic" treatment; animals get this stylized-character treatment instead.
