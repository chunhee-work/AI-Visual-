**Rule (locked 2026-06-09):** When crafting storyboards (image OR Seedance video), think LIKE A CINEMATIC DIRECTOR. The audience is watching a cinematic trailer — every panel/shot must consider POV, anticipation, concealment, reveal, emotional rhythm. NOT a character reference sheet where every figure stands face-to-camera body-squared.

**Why:** 2026-06-09 — user explicit directive: "think like a director, the character should not always showing their face or look at the camera. cuz this is a cinematic video, think like how user watch the video, use cinematic director skill when u creating the storyboard." The Land of Hope trailer is a cinematic piece — direct face-to-camera framing in every panel reads as character-sheet flat, breaks immersion, kills cinematic mystery.

## How to apply — cinematic director's toolkit

When drafting any panel/shot, ask:
1. **Whose POV is the audience inhabiting in this beat?**
2. **What information should be CONCEALED to build anticipation?**
3. **What should be REVEALED for emotional impact?**
4. **What angle/framing creates the strongest emotional read?**

### Framing variety (rotate freely — don't default to head-on face)

| Framing | When to use |
|---|---|
| **OTS (Over-the-shoulder)** | Conversation, witnessing, eyes-of-X-watching-Y; subject's back partially in FG |
| **Profile / 3-quarter** | Hero meeting, charged moments — feels more cinematic than face-to-camera |
| **Silhouette** | Reveals are postponed; figure backlit against fire/moon/chi |
| **Back-to-camera** | "Standing with the hero against what's ahead" — audience positioned WITH character |
| **Detail close-up** | Single hand gripping weapon, foot stepping, eye glint, single paper crane fluttering, chopstick tip blazing — let detail carry the beat |
| **Reaction shot** | Show the WITNESS's face/eyes reacting to action that's off-frame |
| **Through environment** | Frame through doorway / window / between cottage walls / behind objects — adds depth + voyeur quality |
| **POV (eyes of character)** | What the character sees — pulls audience into their experience |
| **Low angle hero / High angle drone** | Vary vertical — low makes heroic, high makes vulnerable/wide scope |
| **Dutch tilt** | Unease, action, chaos |
| **Foreground occlusion** | Cranes / embers / chi mist drift through FG partly hiding the subject — adds depth + mystery |
| **Rack focus** | One subject sharp, another soft — pulls eye to specific emotional anchor |

### When face-to-camera IS appropriate

- The hero REVEAL beat (Panel showing "look who arrived") — one panel of the sequence, not every panel
- The emotional climax close-up where the character's expression IS the beat
- Direct eye contact between the audience and the hero in a "rallying cry" moment

NOT for: establishing shots, action shots, transitional beats, aftermath, environmental wides, mood/setup beats.

### Concealment principles

- The viewer doesn't need to see the full face to feel the character's presence
- A clenched hand can carry more emotion than a clenched expression
- A silhouette against fire glow reads more cinematic than a fully-lit hero front-on
- Reveal the face when the BEAT needs it, not because the character is on screen

### Audience POV rhythm

Across 6 panels of a sheet, alternate:
- WIDE → DETAIL → OTS → MEDIUM → CLOSE-UP profile → WIDE finale (etc.)
- Don't put 6 medium shots face-to-camera in a row
- Build through concealment → tease → reveal → action → release

## Workflow integration

1. **Before writing panel descriptions**, sketch the camera/POV intent for each beat
2. **Vary across the sheet** — if Panel 1 is face-to-camera medium, Panel 2 should NOT be face-to-camera medium
3. **Default away from face-to-camera** — make me earn the face reveal beats
4. **OTS, silhouette, detail, back-to-camera, profile are first-class framings** — not "experimental alternatives" to a face-to-camera default
5. **Annotation block** for each panel should reflect the cinematic intent (SHOT TYPE + BEAT TITLE both reflect director language: "OTS — THE WATCHER", "SILHOUETTE — THE STAND", "DETAIL — THE GRIP")
