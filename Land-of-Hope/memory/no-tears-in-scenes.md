**⭐ Rule (locked 2026-06-16):** NO tears / 泪水 / tearful / tear-forming / crying tears in ANY scene moving forward. Applies to ALL characters: HEARTA, ECOX, all 8 OG8, Witness Boy, little peasant girl, villagers, any character.

**Why:** 2026-06-16 — User explicitly said: "no 泪水 in this scene Clip 06F-D V3 (6s). moving forward no 泪水 in all the scene pls take note on this. keep in your memory." Reinforced after multiple prior tear-references in HEARTA close-ups + girl reactions. User wants emotion conveyed through other expressions only, not tears.

**How to apply:**

1. **NEVER write these terms in any prompt:**
   - "tear forming at corner of eye"
   - "tearful expression / tearful face / tearful gasp"
   - "wiping tear"
   - "crying tears"
   - "eyes filled with tears"
   - "single tear rolling"
   - "tears welling up"
   - "tear-streaked"

2. **Replace tear-emotion language with these alternatives:**
   - **Sadness / sorrow:** brow furrowed downward + lips trembling + chin quivering + eyes wide + glassy-eye look (without saying tears)
   - **Compassion:** soft eyes + brow softened + lips parted gentle + hand-on-shoulder gesture
   - **Relief:** breath out + shoulders sagging + eyes closed brief + soft smile
   - **Heartbreak:** mouth small frown + brow furrowed + eyes downcast + chin tucked + body slumped
   - **Determination through emotion:** jaw clenched + eyes hardened + brow set + lips compressed
   - **Anguish (Whisper):** mouth opens + face crinkles + skull-maw distorting + body trembling (already non-human so no tears applicable anyway)

3. **Apply universally:**
   - Past prompts that had tears → moving forward strip those out when revising
   - Future prompts → never include tears even when describing intense emotion
   - Both Seedance video prompts + Higgsfield image prompts

4. **What still IS allowed:**
   - Eye expressions: wide eyes, narrow eyes, eyes blown wide, eyes closed, glassy stare
   - Mouth expressions: agape, parted, frown, trembling, bitten lip
   - Brow expressions: furrowed, raised, set, softened
   - Body posture: trembling, slumped, tense, frozen
   - Breath: gasp, shuddering breath, panting, held breath
   - These convey emotion without tears
