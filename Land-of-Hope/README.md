# Land of Hope — Cinematic Origin Trailer

A ~2:15 cinematic origin trailer for the brand **Gacha — The Chill Farm** / **The Chill Gallery**, produced shot-by-shot in Higgsfield (GPT Image 2) for stills and Seedance 2.0 for video.

## Story Premise

Ten fallen warriors from the golden alien world **AUREA** are corrupted by The Whisper, escape to Earth in WICK's hand-rebuilt ark, and find a "Living Wall" of real usernames where each hero recognizes their Earth mirror ("that could be us"). They vow to become Earth's heroes — humbly, kindly, earned.

## The Locked Two-Block Style (for every GPT Image 2 prompt)

See [`memory/land-of-hope-locked-visual-style.md`](memory/land-of-hope-locked-visual-style.md) for the full prose blocks.

**Structure**:
1. **SHARED STYLE** — premium painterly 3D animation base register (sets the craft bar)
2. **SOFT CINEMATIC LIGHTING** — naturalistic restrained override (controls the actual lighting/color/atmosphere)

The two blocks intentionally contradict on lighting/color — Block 2 always wins. Together they produce painterly cinematic stylized animation with naturalistic soft lighting.

## Style Iteration History

The locked style went through significant iteration this session:
1. Started with old heavy-chiaroscuro hero-keyart keyword block (DEPRECATED)
2. Moved to soft daylight + clean restrained color (good but flat)
3. Tried painterly cinematic Puss in Boots register (close but ambiguous)
4. **Final**: TWO-BLOCK structure — premium painterly base + soft cinematic override

The two-block structure resolves the ambiguity by explicitly contradicting in lighting/color — the soft block always wins, the shared block locks the craft bar.
