**⭐ Rule (locked 2026-06-16):** All storyboard panels and Seedance clips DEFAULT to characters NOT facing the camera. Use back-to-camera / three-quarter / profile / silhouette / OTS framing. ONLY explicit close-up face shots allow face-toward-viewer/camera framing.

**Why:** 2026-06-16 — User reinforced after Sheet 06F/G/H breakdown delivery: "character should not face to the camera, except there's a close up face look." Default face-to-camera reads flat/static + breaks cinematic register. Varied angles create dynamic immersive feel.

**How to apply:**

1. **DEFAULT for any character panel:** back-to-camera / 3/4-back / side-profile / OTS / silhouette framing
2. **EXCEPTION = dedicated close-up face shot:** extreme close-up macro / medium close-up of single character face — these CAN show face toward viewer
3. **Group scenes:** all characters look toward action subject (adversary / target / event / sky / object) — NEVER toward camera
4. **Action panels:** character mid-motion captured from creative angle (low Dutch-tilt / bird's-eye / lateral profile / over-shoulder) — NOT flat front-facing
5. **Hero portrait moments:** prefer 3/4 angle or slight Dutch-tilt over straight front-facing
6. **Close-up face shots eligible for face-to-viewer:** full-face front close-up / 3/4 face close-up / profile face close-up — all count as "close-up face look"

**Examples:**
- ✅ Bird's-eye crane-down with characters looking UP (back-of-head visible to camera)
- ✅ Side-profile of character mid-action with face in profile not facing camera
- ✅ OTS shot looking at target with hero's back/shoulder in foreground
- ✅ Close-up macro of single character's tearful face — face-to-viewer allowed (this IS a close-up face shot)
- ❌ Wide hero shot with character standing front-facing eyes-to-camera
- ❌ Group lineup with all characters facing camera in straight row
